# LV0 筑基·Python与数学（融合内核）

> **本层不再独立成课**，而是作为 **LV1 的"Python 筑基内核"**，有机穿插在 LV1 各课中。

## 为什么融合在 LV1 里？

孩子学 AI，**先要被 AI 震撼**（先用别人的 AI：对话、写诗、作图、问答、查资料……建立"AI 好强大"的认知与兴趣），再在这个兴趣驱动下**学 Python**。若把 Python 单拎成一层，孩子会觉得枯燥、不知道"为什么学"。

所以本内核**不单独成层**，而是围绕 LV1 的**贯穿项目"我的 AI Agent"**，把 Python 知识点**按需穿插**进每一课——

**每课三段式：**
1. **用别人的 AI 震撼/体验**（全能展示，建立认知）
2. **学一段 Python**（从看懂到会写，围绕"怎么把这块能力搬进我的 AI"）
3. **往自己的 AI 里加代码**（贯穿项目进展）

## 双螺旋节奏（Python 知识点按 LV1 课序穿插）

| LV1课段 | 别人的AI（体验） | 穿插 Python 筑基 | 贯穿项目进展 |
|:----:|:----------------|:----------------|:------------|
| 01-03 | 对话/写诗/作图全能秀；提示词入门 | print、变量、input | 创建议题：给自己的AI起名 |
| 04-08 | 作文/学习/画图/汇报/翻译 | 类型、运算符、if分支 | 加"会聊天"：input+print问答 |
| 09-13 | 摘要/数据/提示进阶/工具/多模态 | for循环、列表 | 加"会查资料"：列表+循环检索 |
| 14-17 | 辨真伪/局限/用AI学AI/综合实战 | 字典、函数 | 加"会问答"：字典库+函数封装 |
| 18-20 | 作品展示/复盘/闯关 | 文件读写、异常 | 组装成"自己的全能AI助手" |

## 覆盖考区

- **NOAI A区（Python编程）**：变量/类型/运算符/分支/循环/列表/字典/函数/文件/异常，全程覆盖
- **NOAI E区（数学直觉）**：概率/统计/线性/微积分直觉，穿插于数据处理与作图课
- **LMCC 上机编程**：submission.py 函数实现能力，经"函数/字典/文件"打下基本功
