# LV0 筑基·Python与数学

## 概述

本级别是双体系融合后新增的**筑基层**——打通 NOAI 的 A区（Python编程）与 E区（数学基础），也是 LMCC 上机实操（submission.py）的共同编程地基。

> **设计逻辑**：无论是备考 LMCC 还是冲 NOAI，Python 与数学都是绕不开的地基。本级别从零教起，让零基础学员也能学会写 Python、看懂数学直觉，为后续"懂 AI 原理"与"建模实战"铺路。

## 前置要求

- 无需任何编程/数学基础
- 会打字、会上网即可

## 学习目标

完成本级别学习后，学员应能：

1. 独立编写 Python 程序（变量、分支、循环、函数、数据结构）
2. 掌握列表/字典等核心数据结构（含深浅拷贝）
3. 使用 numpy/pandas 处理数据
4. 具备阅读 Python 代码的能力（呼应 NOAI 初赛"脑跑代码"）
5. 理解概率统计、线性代数、微积分的核心直觉（不追求严谨推导）
6. 用 Python 做数据处理与可视化的综合小项目
