# LV2 懂AI（原理认知篇）

## 概述

本级别承接LV1"会用AI"的切身体验，正式进入**"AI背后的知识"**——回答学员心中最大的疑问："AI到底是怎么学会的？为什么它这么厉害，又为什么偶尔胡说八道？"

核心理念是**"从现象到原理"**：每一课都从LV1中用过的现象出发（比如"AI为什么能接话"、"为什么画得这么像"），再引出背后的原理（下一词预测、注意力机制、神经网络）。不做数学推导，重直觉、重类比、重可视化。

> **设计逻辑**：先有体验，再讲原理——原理讲的是学员"见过的东西"，而非抽象概念，学起来不枯燥、记得住。

## 前置要求

- 建议先完成LV1课程（至少体验过AI聊天、AI绘画等场景）
- 无需编程基础，无需高等数学

## 学习目标

完成本级别学习后，学员应能：

1. 描述AI"学习"的基本图景：数据→模型→训练→能力
2. 说明数据在AI中的作用与来源
3. 区分监督学习、无监督学习、强化学习三种范式（用生活案例）
4. 用直觉理解神经网络与深度学习（神经元、层、训练）
5. 理解文字如何被数字化表示（词向量、语义空间）
6. 解释Token的概念及大模型"分词"的工作方式
7. 说明大语言模型的本质——基于概率的"下一个词预测"
8. 用生活类比解释注意力机制（AI如何找重点）
9. 描述大模型"会聊天"的训练三部曲（预训练、指令微调、人类对齐）
10. 讲述大模型从统计语言模型到ChatGPT的演进简史
11. 解释AI幻觉的根源，以及Scaling Law与涌现能力
12. 说出模型从训练到上线的完整生命周期（含评测与部署）
13. 认识主流大模型家族与开源/闭源生态
14. 理解AI编程的基本原理（代码即文本）
15. 了解高效微调（LoRA）的基本思想，亲手完成专属模型微调实验
16. 亲手完成注意力可视化实验
17. 画出"AI工作原理"的完整概念图

## LMCC考纲对标

本级别是LMCC考纲的核心覆盖区，对应第一章"大模型基础与架构"（考点1-6）、第二章"预训练技术与人类对齐"（考点7-12）、第三章"解码部署"（考点13-14）的主要原理层内容，并将"模型评测流程及指标"（考点20）融入第14课。考点全覆盖对照见各课教学大纲"对应LMCC考点"列。

## 教学建议

1. **重可视化教学**：Transformer、注意力、神经网络等概念抽象度高，务必使用交互式可视化工具（如LLM可视化平台、t-SNE演示、注意力热力图）辅助讲解，让原理"看得见"。

2. **从现象切入**：每课开场先用一个LV1中真实的体验现象"钩住"学员（"还记得上次AI接话吗？今天告诉你它怎么做到的"），再讲原理，切忌直接抛概念。

3. **类比优先、公式靠边**：用"猜词游戏"解释自回归，用"聚光灯"解释注意力，用"图书管理员"解释检索。数学公式仅在学有余力的学员中作为扩展材料。

4. **两节实验课充分利用**：第17课的微调实验与第18课的注意力可视化是全级别的亮点，建议安排在机房/实验室，让学员亲手微调迷你模型并观察注意力热力图，用实验结果反证前面所学的理论。

5. **勾连模型生态**：每讲一个概念，皆指明其在主流模型（GPT、DeepSeek、通义等）中的具体体现，让学员始终清楚"学这东西跟我在用的AI有什么关系"。

6. **控制深度**：本级别是通识而非专业课程。任何概念讲清楚"是什么、为什么、跟我有什么关系"即可，不追求技术细节完备。
