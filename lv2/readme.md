# LV2 大模型核心技术（模型原理篇）

## 概述

本级别深入剖析大语言模型的核心技术原理，从Transformer架构出发，系统讲解预训练、指令微调、人类对齐、解码部署等关键技术环节，帮助学员真正理解大模型"为什么行"以及"怎么训练"。

## 先修要求

- 建议先完成LV1课程
- 具备Python编程基础
- 了解基本机器学习概念

## LMCC 认证对标

本级别对应LMCC第一轮考试中"模型架构、预训练、微调对齐"等核心技术考点，同时为第二轮编程题奠定理论基础。

## 学习目标

完成本级别学习后，学员应能够：

1. 解释Transformer架构的核心组件及其设计原理
2. 区分自注意力机制中的不同类型注意力掩码及其用途
3. 对比主流的开源大模型架构（GPT、LLaMA、Mistral、MoE）之异同
4. 描述预训练数据处理的完整流程与关键技术
5. 理解Tokenization各算法（BPE、WordPiece、SentencePiece）的工作原理
6. 阐述Scaling Law的基本规律及涌现能力的触发条件
7. 掌握指令微调（SFT）的数据构建方法与质量要求
8. 使用LoRA等高效微调技术完成模型微调的实践操作
9. 说明RLHF与DPO等人类对齐技术的核心思路与区别
10. 理解不同解码策略（贪心、束搜索、采样）的权衡与适用场景
11. 掌握KV Cache、FlashAttention等主流推理加速技术的原理
12. 完成开源模型的本地部署与推理测试

## 教学建议

1. **重可视化教学**：Transformer架构、注意力机制等概念抽象度高，建议大量使用交互式可视化工具辅助讲解，帮助学员建立直观认知。

2. **实践驱动理论**：微调实践课（11-12课）建议与理论课交替进行，让学员在实践中验证理论，避免纯理论讲解导致的枯燥感。

3. **注意分层教学**：本级别知识跨度大，从架构原理到量化部署均有涉及。可将学员按基础分组，对基础薄弱者重点讲解前12课核心内容，对学有余力者引入DeepSpeed、Megatron等分布式训练框架作为扩展。

4. **配合代码展开**：Transformer、注意力机制、位置编码等章节均配有核心代码实现。建议以"先跑通、再理解、后改写"为节奏，鼓励学员动手修改关键参数观察效果变化。

5. **对齐现实需求**：每讲一个新概念，皆指明其在主流模型（如LLaMA、ChatGPT、Claude）中的具体体现，让学员始终清楚"学这东西有什么用"。
