## 课程简介

CCF大模型能力认证（Large Model Competence Certification，简称LMCC）由中国计算机学会（CCF）主办，是国内权威的大模型领域能力认证考试。本课程由**智国学堂（TeachZero）** 倾力打造，系统覆盖LMCC认证全部知识点，助学员从零基础到掌握大模型核心能力。

课程秉持**"先用后懂"**的通识化教学理念：先让学员在真实场景中**用AI**——写作、绘画、办公、学习、创作，建立信心与兴趣；再逐步进化到**AI背后的知识**——数据、神经网络、大模型原理；进而**驾驭AI**去创造作品；最终培养**思辨AI**的素养。教学法通识化、由浅入深，但**LMCC考纲24考点一个不少**，学完即可备考。

课程不设门槛，零基础可学，通用混龄，从小学高年级到成人皆宜。

## 课程概览

本课程共计80课时，分4个级别，逐层递进：

| 级别 | 名称 | 课时 | 定位 | 一句话 |
|:----:|:-----|:----:|:-----|:------|
| LV1 | 会用AI（应用体验篇） | 20 | 先玩起来 | 先用AI，建立信心与兴趣 |
| LV2 | 懂AI（原理认知篇） | 20 | 背后的知识 | 进化到AI背后的知识 |
| LV3 | 驾驭AI（创造应用篇） | 20 | 用AI造东西 | 从使用者变成创作者 |
| LV4 | 思辨AI（素养未来篇） | 20 | 与AI共处 | 培养AI时代独立思考素养 |

**学习路径**：会用 → 懂 → 驾驭 → 思辨。四级环环相扣：LV1的体验是LV2原理学习的锚点，LV2的原理支撑LV3的创造，LV3的创造实践引发LV4的伦理思考。

## 课程特色

- **🎯 先用后懂**：先从"用AI"开始，在真实场景中建立信心与兴趣，再深入"AI背后的知识"，由表及里
- **🧰 场景驱动**：写作、绘画、办公、学习、创作……每课一个真实场景，学完就能用
- **🛠 动手贯穿**：从提示词到API到Agent，每级都有实操项目，边做边学，做中学
- **🌏 通识素养**：伦理、安全、隐私、未来——培养AI时代独立思考的公民素养
- **🔗 全龄适用**：零基础可学，不设技术门槛，通用混龄，青少年与成人皆宜
- **📋 考点全覆盖**：通识化教学法 + 完整LMCC考纲24考点，学完即备考

## 目标学员

- 想用AI提升学习与工作效率、却不知从何入手的初学者
- 已会用AI聊天、想系统提升AI能力的进阶者
- 希望孩子掌握AI素养的家长与中小学生
- 从事AI教育的教师、培训机构讲师
- 对人工智能与大模型感兴趣的任何年龄段自学者

## 前置知识

| 级别 | 前置要求 |
|:----:|:---------|
| LV1 | 无需任何前置知识，会打字、会上网即可 |
| LV2 | 建议先完成LV1（有AI工具使用体验） |
| LV3 | 建议先完成LV1-LV2（有原理认知基础） |
| LV4 | 建议先完成LV1-LV3（有完整的用/懂/造体验） |

## 使用方式

1. 按级别顺序学习：LV1 → LV2 → LV3 → LV4
2. 每课时含教案框架（lesson.typ，基于 lmcc-theme.typ 主题渲染）
3. 每级别末设综合项目、单元测验与复盘课
4. 建议结合在线AI工具与实操平台同步学习
