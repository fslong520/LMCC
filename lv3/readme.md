# LV3 驾驭AI（创造应用篇）

## 概述

本级别实现从"用AI"到"造东西"的跨越——学员将不再只是AI的使用者，而是用AI创造作品的**创作者**。从提示工程进阶到API调用，从RAG知识库到Agent智能体，最终完成一个端到端的综合AI项目。

核心理念是**"做中学"**：每个知识点都配一个可交付的作品（一个问答程序、一个知识库、一个自动助手、一个音视频作品……），学完就能拿出成果。

> **设计逻辑**：LV1会"用"，LV2懂"理"，LV3要会"造"——把前两级的体验与原理转化为真实生产力，建立"我能用AI创造价值"的自信。

## 前置要求

- 建议先完成LV1、LV2课程
- 不需要深厚的编程功底，但需要有基本的电脑操作与逻辑思维
- API与编程内容以"能跑通、能改参数"为最低要求，学有余力者再深入

## 学习目标

完成本级别学习后，学员应能：

1. 掌握高级提示工程技巧，能针对复杂任务设计结构化提示词
2. 理解API的概念，能调用大模型API完成基本的问答应用
3. 用AI辅助编程，独立完成小型工具或应用（含Python基础）
4. 使用无代码/低代码平台搭建自动化工作流
5. 理解RAG（检索增强生成）的原理与进阶技术，搭建个人知识库并实现文档问答
6. 认识Agent的概念与架构（含Function Calling），搭建一个能自主执行任务的智能体
7. 掌握多模态创作工作流（图文音视频）的基本方法
8. 制作AI音视频作品（配音、音乐、数字人）
9. 搭建个性化AI学习助手
10. 运用AI完成小说、漫画、剧本等创作工作流
11. 独立完成"我的AI作品"综合项目的规划、开发、调试与打磨（含基础评测）
12. 完成作品的展示、互评、发布与分享
13. 梳理个人AI技能树，明确后续进阶方向

## LMCC考纲对标

本级别对应LMCC考纲第三章"解码部署与提示学习"（考点15-16）、第四章"复杂推理与智能体"（考点17-19）、第五章"多模态模型"（考点22）的应用实战层，并将"模型评测"（考点20）融入第16-17课的项目测试与互评。考点全覆盖对照见各课教学大纲"对应LMCC考点"列。

## 教学建议

1. **作品导向**：本级别所有课都围绕"能拿出作品"展开。建议从第1课起就让学员记录"作品灵感本"，第14课综合项目从灵感本中选题。

2. **分层要求**：学员基础差异大，建议对API、编程等内容分层：基础组以"能跑通官方示例、改参数"为目标，进阶组挑战"从零搭建"。无代码平台（Coze等）作为普适入口降低门槛。

3. **工具准备**：开课前统一规划API额度、无代码平台账号、知识库工具等资源，避免课堂上因账号/额度问题卡壳。可安排小组共享账号。

4. **真实问题驱动**：综合项目选题鼓励解决学员自己的真实问题（帮妈妈整理菜谱、帮班级做知识库、做自己的学习助手），真实需求带来真实动力。

5. **展示即学习**：第17-18课的项目展示与发布不可省略——路演、互评、接受反馈，是"做中学"闭环的关键一环，也锻炼表达与协作能力。

6. **衔接下一级**：创作与分享中自然会遇到版权、隐私、伦理问题（如"我的作品用了AI生成的内容算不算我的"），适时留白，引导学员带着问题进入LV4思辨课程。
