# LV3 进阶应用与开发（应用实战篇）

## 概述

本级别聚焦大模型的实战应用与开发技能。学员将深入学习提示工程进阶技巧、检索增强生成（RAG）、智能体（Agent）开发等前沿技术，并通过多个实战项目将理论转化为实践能力，全面备战LMCC第二轮编程考核。

## 前置要求

- 完成LV1-LV2课程
- 具备Python编程与API调用经验
- 了解基本Linux操作

## LMCC对标说明

本级别对应LMCC第一轮中"提示词、RAG、Agent"等进阶概念，以及第二轮编程题中的"大模型应用、训练和微调"实践技能考核。

## 学习目标

完成本级别学习后，学员应能：

1. 掌握高级提示工程技巧，包括系统提示设计、复杂Prompt编排与结构化输出控制
2. 理解RAG技术原理，熟悉Embedding、向量数据库与检索策略的核心机制
3. 基于LangChain等框架独立构建文档问答系统，实现端到端RAG应用
4. 运用高级RAG技术（分块策略、混合检索、重排序）优化检索质量
5. 实现Function Calling与工具定义，打通大模型与外部系统的调用链路
6. 掌握ReAct与Plan-then-Execute等Agent架构设计方法
7. 开发多Agent协作系统，实现Agent间的分工、通信与协调
8. 应用复杂推理技术（ToT、GoT、Self-Refine）提升模型推理能力
9. 使用Flask/FastAPI开发模型服务API，完成部署运维全流程
10. 完成RAG知识库、Agent工作流、领域微调、模型评测四大综合项目

## 教学建议

1. **动手为先**：LV3是实战级别，代码即讲义。每节课的核心内容应以可运行的代码片段或Notebook为载体，理论讲解压缩至30%以内，留足动手时间。

2. **项目递进**：四个项目（课次14-17）逐级递进，从RAG到Agent再到微调与评测，最终汇聚为课次19的端到端综合项目。每个项目应产出可演示的成果，累积为作品集。

3. **环境前置**：开课首周须完成开发环境配置（Python虚拟环境、API密钥、向量数据库、LangChain等），避免后续课程因环境问题中断。建议提供Docker镜像或云端Notebook方案。

4. **对比切入**：每引入一项新技术（RAG、Agent、Function Calling），先让学员体验"没有它"时的局限，再展示"有了它"的效果，建立感性认知后再讲原理。

5. **考试导向**：课次11专门拆解LMCC第二轮编程题，此后每个项目和练习都应与考试题型和评分标准对接，让学员带着"应试准备"的意识完成实战训练。
