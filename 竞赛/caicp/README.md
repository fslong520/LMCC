# CAICP 人工智能能力认证（Certified AI Competence Program）

> 本目录为 CAICP（人工智能能力认证活动）备赛资料与大纲。
> 官网：https://ioaic.org.cn/caicp

---

## 一、活动概览

- **全称**：Certified AI Competence Program（CAICP），中文全称「人工智能能力认证活动」
- **主办**：IOAI 中国区官方活动（与 NOAI 并列）
- **定位**：面向中小学生的**普及性**人工智能能力认证。难度较低、更具系统性、引导性，覆盖小学/初中/高中
- **与 NOAI 关系**：学术大纲与 NOAI 一脉相承、有内在连续性；NOAI 高难度、高选拔、主要面向高中生；CAICP 是普及版。**2027 年起，CAICP 认证将成为 NOAI 的入场券**
- **晋升通道**：CAICP-E / J / S → 冬令营/省选 → NOAI 中国站 → IOAI 国际赛 / APOAI 亚太赛

---

## 二、三大考察维度

| 维度 | 内容 | 说明 |
|:----|:----|:----|
| **人工智能知识** | 原理 / 应用 / 伦理 | 原理考 AI 三要素（数据、算法、算力）+ 机器学习四范式（监督、非监督、半监督、强化）；强化学习为高频考点 |
| **Python 编程** | 语法 + 读码 + 质量识别 | 2026 版降低语法记忆、强化代码阅读与质量识别；还考「分析代码表现」「识别代码质量」 |
| **计算思维** | 抽象建模 | 把现实问题抽象为可计算形式；典型题：赛制逻辑推理、图形规则推导、基础算法推演（多数不需编程，更似逻辑推理） |

> 设计逻辑：AI 知识=认知框架；Python=实践工具；计算思维=元能力。三者结合，培养「理解 AI、能驾驭 AI」的人。

---

## 三、三个难度级别（E / J / S）

三个级别考察相同三维度，深度依次递进。**学生按水平自报任一级，不限学段，不强制逐级**。

| 级别 | 名称 | 定位 | 关键内容 |
|:----:|:----|:----|:--------|
| **E 级** | 基础级 Elementary | Python 启蒙 + AI 认知入门 | Python 基础语法、AI 基本概念、基础计算思维；不需编程高手、不需竞赛经验 |
| **J 级** | 入门级 Junior | AI 核心知识 + 基础应用 | 在 E 级基础上掌握人工智能核心知识与基础应用；理解机器学习完整流程 |
| **S 级** | 进阶级 Senior | AI 算法初步应用 | 用 AI 算法解决简单预测/分类任务；内容接近大学 AI 导论；是 CAICP 与 NOAI 之间的桥梁 |

> 选级建议：看水平不看年级。有编程基础的初二学生可跳过 E 级报 J 级；零基础高一学生可从 E 级起步。

## 四、考试形式与场次

| 项 | 说明 |
|:--|:----|
| 第一轮 | 90 分钟，全客观题，满分 100 |
| 第二轮 | 120 分钟，含 2 道编程题，满分 150 |
| 晋级 | 第一轮达「荣誉提名」（≥60 分）即晋级第二轮，**晋级资格永久保留** |
| 场次 | 每自然年春秋、秋冬两个场次；每场次每难度均设两轮，在线举办 |
| 冬令营 | 每年寒假与知名高校 AI 学院联合实地举办「CAICP 冬令营」，每年一场 |

## 五、备赛要点

1. **Python 是共同起点**：CAICP-E 考 Python 基础，NOAI 第一轮也考 Python 基础编程——先把 Python 基础打扎实
2. **计算思维常练**：多数为逻辑推理题，练赛制推理、图形推导、基础算法推演
3. **AI 知识框架**：掌握 AI 三要素 + 机器学习四范式（强化学习高频）
4. **读码重于写码**：强化分析代码、识别代码质量的能力
5. **分级进阶**：E → J → S 逐级或按水平跳级；S 级完成可衔接 NOAI 省选

---

## 六、与 NOAI 的关系（衔接路径）

```
CAICP-E（基础）→ CAICP-J（入门）→ CAICP-S（进阶）
        ↓ 冬令营 / 省选推荐
NOAI 中国站（选拔国队）
        ↓
IOAI 国际赛 / APOAI 亚太赛
```

- CAICP 是**普及敲门砖**，NOAI 是**高选拔竞赛**，二者同属 IOAI 中国区体系。
- 信奥/编程生优势：编程能力是存量资产，拆解问题与调优的肌肉记忆可迁移到 AI 建模。
