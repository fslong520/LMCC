## 二、赛题一：广阳岛智能车（75 分）

### 2.1 任务结构（三个综合任务，规模逐级增加）

| 任务 | 物体处理 | 障碍 | 途径点 | 返回 | 起步进度 |
|:----:|:--------|:----:|:-----:|:----:|:--------|
| 综合任务1 | 1 目标物入库 + 1 混淆物清理 | 避1 | 依次4 | 停车区 | 0/8 |
| 综合任务2 | 2 目标物入库 + 2 混淆物清理 | 避2 | 依次6 | 停车区 | 0/13 |
| 综合任务3 | 3 目标物入库 + 3 混淆物清理 | 避3 | 依次8 | 停车区 | 0/18 |

### 2.2 评分项（100 分拆四项）

| 评分项 | 面板满分 | 操作建议 |
|:------|:-------:|:--------|
| 任务完成 | 40 | 优先确保物体处理、绕障、途径点顺序、返回停车区全部达成 |
| 路径与规则 | 25 | 沿道路运行、按序巡检、避免违规或无效绕行 |
| 自主控制 | 15 | 用程序自主完成，减少人工干预 |
| 完成效率 | 20 | 先稳定完成，再缩短路径与等待时间 |

### 2.3 Python 常用指令速查

| 类别 | 指令 | 用途 |
|:----|:----|:----|
| 行驶 | `robot.forward(cm)` / `backward(cm)` | 按距离前进/后退 |
| 转向 | `robot.left_angle(deg)` / `right_angle(deg)` | 原地按角度转向 |
| 任务进度 | `robot.mission()` / `task_state()` | 读任务信息与完成状态 |
| 投放预判 | `robot.release_preview()` | 投放前检查位置 |
| 定位 | `robot.odometry()` | 读里程计/位置 |
| 道路感知 | `robot.road_state()` / `map_graph()` | 读当前道路状态与公开道路图 |
| 道路控制 | `robot.follow_road(100,40,True)` | 沿当前道路行驶（距离/速度/限速） |
| 路口选择 | `robot.take_exit(road_id,40,True)` | 按道路编号进指定出口 |
| 摄像头 | `robot.observe("目标物")` | 识别目标类型与相关信息 |
| 自动接近 | `robot.approach("目标物",100)` | 自动靠近目标 |
| 夹爪 | `robot.grab()` / `release()` / `holding()` | 抓取/释放/查询夹持状态 |

### 2.4 推荐程序结构（伪代码）

```
开始
  读取任务信息与道路状态
  沿道路行驶到目标区域
  识别目标并调整到合适距离
  执行抓取或投放，并检查动作结果
  按规定顺序巡检途径点
  返回停车区，核对任务完成状态
结束
```

### 2.5 五个训练阶段

1. 动作标定：确认前进距离、转向角度与地图比例，记录安全距离
2. 道路导航：路段验证 `follow_road()`，路口验证 `take_exit()`
3. 视觉与夹取：摄像头确认目标名称/置信度/距离，再抓取投放
4. 任务1闭环：物体处理→绕障→4途径点→返回，检查进度 8/8
5. 规模扩展：对象数/途径点/道路编号参数化，迁移任务2、3

### 2.6 可诊断设计

- 关键动作后读 `holding()` / `task_state()` / `road_state()`，判断是否生效
- 导航/识别/夹取/投放/巡检拆成函数，便于单独验证复用
- 循环设最大步数或失败分支，防死循环
- 转向/接近/绕障留安全余量，降碰撞误判

## 三、赛题二：识物工坊（橙子二分类，25 分）

### 3.1 任务目标

训练「橙子 / 非橙子」整图二分类模型（整图分类，不标物体位置），判断一张图是否为橙子。

### 3.2 总流程

```
准备两类图片 → 数据健康度检查 → 浏览器内训练 → 新图/摄像头测试 → 下载模型ZIP+项目备份 → 提交
```

### 3.3 样本准备（决定模型上限）

- **橙子**：不同品种真实橙子，覆盖角度/远近/大小/明暗/背景/遮挡/单个或多个
- **非橙子**：苹果、橘子、橙色球、手、桌面、空背景及其他橙色物体
- 每类至少 5 张才能训练，建议 20 张以上并覆盖多种变化
- 两类数量尽量接近；同一连拍只留少量代表图（避免"背答案"）
- 训练集避免只用同一桌子/灯/摄像头角度；非橙子主动加入易误判的橘子/苹果/橙色物品
- 保留一组从未用于训练的测试图；避免数据泄漏（自测图不入训练集）

### 3.4 训练、测试与导出

| 步骤 | 界面信息 | 建议 |
|:----|:--------|:----|
| 训练门槛 | 每类≥5；页面建议20+ | 不要只满足最低门槛 |
| 批大小 | 8/16/32，默认16 | 样本少保持16，除非多次对比否则不改 |
| 学习率 | 0.0005/0.001/0.003，默认0.001 | 先用默认，不稳定再调 |
| 测试 | 摄像头或图片 | 用未参加训练的新图，记录误判类型 |
| 模型导出 | 下载训练模型 | 保留原始ZIP，不重命名、不重压缩 |
| 项目备份 | 备份项目（含图片） | 每天训练后导出；异机先导入备份 |

### 3.5 模型优化流程

1. 按误判分类：假阳性（非橙认橙）/ 假阴性（漏认橙）
2. 补难例：假阳性多→增相似非橙子；假阴性多→增不同光线/角度橙子
3. 保持两类平衡，重查健康度
4. 重训练，用同一组保留测试图比较
5. 确认改善再下载新模型 ZIP，记录版本日期

### 3.6 正式提交要求

| 项目 | 要求 |
|:----|:----|
| 文件 | 训练台导出的完整模型 ZIP |
| 类别 | 必须且只能含「橙子」「非橙子」两类 |
| 大小 | ZIP ≤ 2 MiB |
| 完整性 | 勿重压缩或改动内部文件 |
| 计分 | 以最后一次提交为准 |
| 成绩显示 | 选手端只显示提交回执，不显示保密测试集结果 |

## 四、平台环境与浏览器内运行

- Python 运行时在浏览器加载 **Pyodide/WASM**，首次可能需数十秒；"环境准备中"过久则刷新一次
- 识物工坊数据保存在**本机浏览器**，不会自动上传；清理网站数据可能删项目，须定期导出备份
- 图片格式：JPG / PNG / WebP，单张 ≤ 15MB

## 五、备赛要点（一页速查）

**赛题一 Python**：写代码 → 重置 → 运行 → 看状态/3D/实时评测 → 分段修正 → 核对正式提交
**赛题一 Blockly**：搭积木 → 自动保存 → 重置 → 运行/暂停/停止 → 看任务进度 → 核对比赛记录与提交
**赛题二**：采样 → 健康度检查 → 浏览器训练 → 新图测试 → 下载模型 ZIP + 项目备份 → 比赛提交

### 关键原则
1. 稳定完成：先完成全部任务，再优化路线与速度
2. 完整留存：保存程序版本、项目备份、模型 ZIP 与提交回执
3. 区分状态：运行、自动保存、实时评测、正式提交是不同环节
4. 正式规则：实时评测仅供参考，最终成绩以后台计算为准
