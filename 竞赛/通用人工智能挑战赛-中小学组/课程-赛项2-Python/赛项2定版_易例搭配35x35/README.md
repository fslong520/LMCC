# 赛项2 识物工坊 · 易例搭配 35×35 定版

## 这是什么

经过**本地暴力搜索 + 平台实测**找到的最优数据集配方。相比此前的「难例堆满」策略，本配方把非橙子类里**易例（明显不像橙子的图）提到一半以上**，平台验证稳定在 **92–100%**。

## 素材构成

| 类别 | 张数 | 挑选规则 |
|---|---|---|
| 橙子 | 35 | 按「像橙子程度」AI 打分排序，取前 35（全部 8–10 分：整果特写、带叶、橙黄鲜明） |
| 非橙子 | 35 | 难例 15（`not_orange` 前 15：青柠、橙汁、切块、树、同类色干扰物）+ 易例 20（`not_orange_easy` 前 20：香蕉、苹果、绿叶、明显异色物） |

**要点**：非橙子里易例必须占一半以上。全用难例会掉到 62–80%（本地验证）。

## 平台实测成绩

| 配方 | 验证准确率（多次重训） | 平均 |
|---|---|---|
| 本配方 35 + 35 | 92 / 92 / 100 / 100 | **96** |
| 变体 40 + 39 | 100 / 92 / 92 | 94.7 |
| 旧方案 M30（30+30 全难例） | 90 / 90 / 90 | 90 |

平台验证集仅 12 张（自动留 15%，同一连拍组不跨集合），单张差异即 8%，故须多次重训取分布，不可看单次分数。

## 模型存档

| 文件 | 验证成绩 |

| `识物模型_35x35_平台100.zip` | 100%（12/12 全对） |

上传比赛建议用 `识物模型_35x35_平台100.zip`；若要更稳，可本地重训后再导出一版。

## 原理（训练台内幕）

从导出模型的 `metadata.json` 解出：

```
底座：MobileNetV2 alpha 0.5（ImageNet 预训练，冻结）
输入：224×224
分类头：Dense(100, relu) → Dense(2, softmax)
训练：10 轮 / 批 8 / 学习率 0.001
```

导出的 `weights.bin` 仅 513KB —— 只有分类头，底座不导出（在浏览器本地）。

## 本地复现方法

1. `uv run --python 3.12` 装 TensorFlow 2.21（CPU）
2. `MobileNetV2(alpha=0.5, include_top=False, pooling='avg', weights='imagenet')` 冻结提特征 → 1280 维
3. 逻辑回归做分类头，`balanced_accuracy_score` 评估
4. M30 素材本地得 88.9%，平台 90% —— 复现成功

**暴力搜索的关键教训**：验证集必须**固定且模拟真实测试分布**（橙 + 难例 + 易例混合）。若训练集和验证集同源（都从易例池抽），会出现「纯易例 96%」的虚高假象。
