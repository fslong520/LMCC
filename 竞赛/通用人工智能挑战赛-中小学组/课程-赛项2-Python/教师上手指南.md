# 赛项2 Python 备赛课 · 教师上手指南（Windows 版）

> 写给要用这套《识物工坊 Python 备赛课》（6 讲）的老师。
> 目标：照本指南做，**40 分钟内配好上课环境，每讲任务链能一步一步走完**。
> 讲义在 `lesson.typ`（投影/打印用），课堂脚本在各讲 `课堂脚本/` 目录，逐个运行。

---

## 一、这门课长什么样

- **6 讲**，每讲三件套：讲义 PDF（投屏）+ 课堂脚本（学生跟着跑）+ 作业
- 学生**不写训练代码**——识物工坊在比赛平台的浏览器里训练。Python 的用途是两件：**备好数据**（批量整理图片）+ **弄懂原理**（训练台黑盒里在干什么）
- **引导式上法**：每个脚本开头是一张【任务卡】。三拍节奏——
  1. **抛任务**：只念任务卡，让学生**先猜**"屏幕上会输出什么"
  2. **跑**：学生亲眼看输出，和猜的对账
  3. **改**：按任务卡的"试一试"改一行，重跑看变化
  猜错不是坏事——猜错再验证，印象最深。

## 二、环境配置（任务 0，一次配好）

> 只需做一次。机房已有 Python 的老师可跳到任务 0.4 验证。

### 任务 0.1 安装 Python（10 分钟）

1. 打开官网下载页：https://www.python.org/downloads/windows/
   （打不开就用华为镜像：https://mirrors.huaweicloud.com/python/ ，选 3.12.x 的 `python-3.12.10-amd64.exe`）
2. 双击安装。**第一屏最下面一行"Add python.exe to PATH"必须勾上**——90% 的"python 不是内部命令"都是漏了这一步
3. 点 Install Now，等完成

**验证**：按 `Win+R`，输入 `cmd` 回车，在黑窗口里输入：

```
python --version
```

预期输出：`Python 3.12.x`。

- 显示"不是内部或外部命令"→ 重装并勾选 PATH；或试试 `py --version`（py 启动器装 Python 时会附带）
- 机房还原卡的，装完 Python 后记得提交还原点

### 任务 0.2 给 pip 换国内源（2 分钟）

同在 cmd 里执行（一行）：

```
python -m pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

预期输出：`Writing to ...pip.ini`。不换源下载会慢甚至超时，机房网络差时尤其必要。

### 任务 0.3 安装库（分讲需求）

| 讲次 | 需要的库 | 什么时候装 |
|:----:|:---------|:----------|
| 第 1 讲 | 无（只用标准库） | —— |
| 第 2、3 讲 | pillow | 上第 2 讲前 |
| 第 4、5 讲 | 无 | —— |
| 第 6 讲 | numpy、scikit-learn | 上第 6 讲前 |

嫌分次麻烦，一次装齐（2 分钟）：


预期：出现 `Successfully installed ...`。装 sklearn 约 60MB，机房第一次装请耐心。

### 任务 0.4 环境体检（1 分钟）

把整个 `课程-赛项2-Python` 文件夹拷到教师机（U 盘或 git 拉取均可），cmd 里 `cd` 进该目录，运行：

```
python check_env.py
```

预期输出每行都是 `[OK]`（sklearn 一行 `[可装]` 也不影响第 1—5 讲开课）。

## 四、常见坑（机房实录）

1. **python 不认识**：装的时候没勾 Add to PATH。重装勾上，或临时用 `py` 代替。
2. **pip 下载超时/SSL 报错**：没换源。回任务 0.2；别在校园网认证页没过的情况下装。
3. **中文乱码**：脚本输出在老 cmd 里乱码时，先执行 `chcp 65001`（切 UTF-8），或改用 Windows Terminal。脚本已尽量避免出问题的字符。
4. **路径**：所有脚本都用相对路径找素材，上课时**先 cd 到脚本所在目录再运行**。整门课的文件夹别改名（"测试素材"这个名字被脚本引用）。
5. **杀毒软件拦 python/pip**：把 Python 安装目录加入信任区。
6. **第 6 讲 sklearn 装不上**（老机器/无网络）：跳过第 6 讲不影响比赛——它只是进阶理解。1—5 讲已覆盖备赛全部刚需。

## 五、和识物工坊比赛的衔接

- 讲义讲"为什么"，平台练"怎么做"。建议：第 3 讲上完进平台做一次真实采样与训练；第 5 讲上完再进平台按"误判→补难例→重训"跑一轮；最后用第 6 讲对照实验收束"数据决定上限"。
- 平台注意（官方手册 V2.0）：浏览器内训练、模型 ZIP ≤ 2MiB、以最后一次提交为准、成绩以后台计算为准。
