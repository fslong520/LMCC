# 识物工坊测试素材（橙子 / 非橙子）

> 本目录为"赛项2·识物工坊（橙子二分类）"备赛的**测试图片素材**，供学生练习采样、健康度检查、测试模型。
> 来源：Wikimedia Commons（开放授权，用于本地测试）。

## 目录

| 目录 | 类别 | 数量 | 说明 |
|:----|:----|:----:|:----|
| `orange/` | 橙子 | 40 | 各类真实橙子（整果/切片/堆叠/不同背景） |
| `not_orange/` | 非橙子 | 40 | **难例**为主：橘子、杏、南瓜、柿子、橙球等橙色调近物（易误判为橙子） |

共 80 张，两类数量均衡（各 40，符合识物工坊"每类建议 20+、两类尽量接近"），已按内容去重（无重复图）。

## 用途

- **采样练习**：学生用 Python（第1/3讲）遍历、统计、去重这两类
- **健康度检查**：观察重复/模糊/类别错误的图（第3/4讲）
- **测试模型**：识物工坊训练后用"未训练"的新图测（第5讲）
- 两类数量接近 + 非橙子含难例——正是识物工坊的高分备赛数据形态

## 说明

- 图片均为 JPEG，宽约 330px，来源 Wikimedia Commons（CC 授权，本地测试用）
- 训练/测试时请按第3讲**8:2划分**，保留一组"从未训练"的测试图，防数据泄漏
- 若需商用/公开，请替换为自有或明确授权素材
