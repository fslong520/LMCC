## 二、2026-09-18 清洗记录（重要）

**起因**：哥哥指出素材两个问题——①橙子图大量重复、青柠柚子混入；②非橙子里竟有橙子。

**做法**：三路并查
1. **感知哈希去重**（aHash 10×10，汉明距离 ≤3 判近重复）——查全 155 张，揪出 3 对完全同图
2. **逐张视觉质检**（`dim image read`，215 张全检，并行 6 路）
3. **人工目视复核**（可疑图放大成拼图，逐张看）

**结果**：

| 问题 | 处理 | 例 |
|:----|:----|:---|
| 橙子目录混入柑橘近物 | **转 not_orange 当难例**（不是删） | 青柠、柚子切面、丑橘、橘瓣、黄绿柑橘 9 张 |
| 橙子目录混入非照片 | 剔除 | 黑白老照片、橙皮人偶、人物持篮 3 张 |
| 橙子目录重复 | 剔除 | `orange_0` ≡ `wm_orange_new_040` |
| **非橙子目录里其实是橙子** | 剔除 | 树上橙、橙子堆、剥皮橙、橙子切面 21 张 |
| 非橙子目录非照片 | 剔除 | 手绘版画、黑白南瓜田 |
| 非橙子目录噪声 | 剔除 | 发霉水果、南瓜、杏、胡萝卜、松果、人物合影 |
| 易例目录非照片 | 剔除 | 古籍手稿、解剖素描、风景画、模糊抽象图 |
| 新增图与旧图同源 | 剔除 | `tg_*` 与 `wm_notor_*` 9 对完全相同 |

**教训（可直接进课堂）**：连"人工整理过"的素材都有 30%+ 的问题率——青柠、柚子、未熟柑橘与甜橙的视觉边界本就模糊，**这正是识物工坊"数据健康度检查"环节的价值所在**。`_reject_20260918/` 就是现成反例教具。

**多样化橙子**特意按 12 个分类拉取，避免再堆同质"橙子堆"：橙汁、橙皮、白底橙、血橙、脐橙、瓦伦西亚橙、橙树、切橙、橙片、橙子容器等。质检后**只留橙子本体**，滤掉纯橙汁/橙皮/甜品/图表/花叶等 103 张。

## 四、用途

- **采样练习**：学生用 Python（第1/3讲）遍历、统计、去重这两类
- **健康度检查**：观察重复/模糊/类别错误的图——`_reject_20260918/` 是现成反例教具
- **测试模型**：识物工坊训练后用"未训练"的新图测（第5讲）
- **难例教学**：`not_orange/` 里 `hard_*`/`tg_*`/`pm_*` 专供"假阳性"专项训练
