# 识物工坊测试素材（橙子 / 非橙子）

> 本目录为"赛项2·识物工坊（橙子二分类）"备赛的**测试图片素材**，供学生练习采样、健康度检查、测试模型。
> 来源：Wikimedia Commons（开放授权，用于本地测试）。

## 目录

| 目录 | 类别 | 数量 | 说明 |
|:----|:----|:----:|:----|
| `orange/` | 橙子 | 40 | 各类真实橙子（整果/切片/堆叠/不同背景） |
| `not_orange/` | 非橙子 | 40 | **难例**为主：橘子、杏、南瓜、柿子、橙球等橙色调近物（易误判为橙子） |
| `not_orange_easy/` | 非橙子（对照组） | 40 | **普通非橙子**：键盘/建筑/绿植/汽车等非橙色调（与橙子明显不同） |

共 80 张正样本 + 40 对照组，两类数量均衡，已按内容去重（无重复图）。

## 对照实验：数据难度 vs 精度

用同一套橙子（40）、同一模型（决策树）、同一特征（缩略像素+颜色），只换非橙子类别：

| 非橙子类别 | 测试精度 | 假阳性 | 假阴性 |
|:----------|:-------:|:-----:|:-----:|
| 难例（`not_orange/`，橘子/杏/南瓜） | 62.5% | 3 | 3 |
| 普通（`not_orange_easy/`，键盘/建筑/绿植） | **87.5%** | 2 | 0 |

**结论**：数据是模型上限。非橙子越"像橙子"（难例越多），模型越难分、精度越低；普通非橙子明显好分，精度从 62.5% 升到 87.5%（假阴性归零）。
这也印证识物工坊备赛的核心——**难例决定区分度**：想拿高分要"补得准"，但也要知道难例本就会压低表面精度。教学上可用此对照讲"数据质量 vs 模型表现"。

- **采样练习**：学生用 Python（第1/3讲）遍历、统计、去重这两类

- **测试模型**：识物工坊训练后用"未训练"的新图测（第5讲）
