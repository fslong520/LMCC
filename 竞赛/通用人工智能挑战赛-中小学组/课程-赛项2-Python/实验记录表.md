## 五、平台操作坑（重要）

1. **上传控件需用户手势**：页面必须在前台可见（`visibilityState=visible`），标签切到后台会导致上传静默失败
2. **用真鼠标事件点击按钮**（CDP `Input.dispatchMouseEvent`），JS 的 `.click()` 不被浏览器认可为用户手势
3. **新建项目/清空后必须刷新页面**，否则上传控件进入异常状态
4. 训练台每类样本上限 **100 张**
5. 注入前调用 `Page.bringToFront` 确保页面在前台
6. **（9/25 晚实锤）目标类别只由专用文字按钮切换**：「为橙子/非橙子添加图片」点击后 React 记住目标；卡片里的「添加图片」**不切类别**——类别非空后文字按钮消失，故正确姿势是**每类空时一整包注入**（100 张 × 320px/q72 ≈ 1.3MB 单次可行）
7. urlgo `eval` 不等 Promise（`Runtime.evaluate` 未开 `awaitPromise`），异步注入须自写 CDP 驱动（见 `.workbuddy/tmp_wk/wk_cdp.py`）

- **划分种子不是常量**。`reval.py` 里的 `1592594996` 只对当时那份数据成立，数据一变种子就变（应是按数据集哈希派生）。所以"预测划分 → 只扫验证集"**只能用于当前状态一次性核对**，不可跨状态复用。上一节"预测出 17/24 与报告吻合"只是**取整数**对上了，划分本身没验证成功。
