# 赛项2「识物工坊」定版素材包 · 前 30 名方案

> 2026-09-18 定版。训练台实测：**连续 3 次验证准确率稳定 90%**。

## 一、包内文件

| 文件/目录 | 内容 |
|:----|:----|
| `orange_30/` | 橙子 **30 张**（按"像橙子程度"排序后的前 30 名，最典型的橙子） |
| `not_orange_30/` | 非橙子 **30 张**（柑橘难例 9 + 其他水果 8 + 橙色物体 6 + 日常 5 + 其他 2） |
| `识物模型_前30名_验证90.zip` | 训练台导出的模型包（0.49 MiB，含 model.json / weights.bin / metadata.json） |

## 二、怎么用

### 1. 在识物工坊训练（生成自己的模型）
1. 打开 `competition.chenlongrobot.com/workshop/`
2. 「新建项目」清空后**刷新一次页面**（否则上传控件可能失效）
3. 上传 `orange_30/` 到「橙子」类，`not_orange_30/` 到「非橙子」类
4. 展开「高级训练设置」，设为 **训练轮次 10、批次大小 8、学习率 0.001**
5. 点「开始训练」，约 3 秒完成
6. 点「下载训练模型」得到参赛 ZIP

### 2. 直接提交已有模型
若要提交随包的模型，先确认 ZIP 内三件齐全、大小 ≤ 2 MiB，再上传比赛提交页。

## 三、关键参数与实验依据

**定版配置**：橙子 30 张 + 非橙子 30 张，轮次 10 / 批次 8 / 学习率 0.001。

各档位实测（同样参数，多次复现）：

| 橙子取排序前 N 名 | 验证准确率 | 复现次数 |
|:----:|:----:|:----:|
| 25 名 | 未测成 | — |
| **30 名** | **90%** | 3 次一致 |
| 40 名 | 92% | 5 次一致 |
| 60 名 | 72% | 3 次一致 |
| 80 名 | 74% | 3 次 |
| 100 名 | 83% | 3 次 |

**结论**：
1. **橙子类越纯越好**——取排序前 30~40 名最优，加入排名 41 名之后的中等图会显著掉分（92% → 72%）
2. **数量不是关键**，纯度才是
3. **同素材同参数下训练是确定性的**，多次训练结果一致，不存在随机波动
4. 学习率 0.001 配少轮次（10）优于 0.0005 配多轮次（50 轮过拟合掉到 74%）

## 四、排序方法（可复现）

用视觉模型对橙子图逐张打分（1-10，"像橙子的程度"），排序后取前 N：

- 10 分：标准橙子特写或清晰整果
- 8-9 分：橙子为主、画面干净
- 6-7 分：橙子可辨但有干扰
- 4-5 分：橙子只占一部分或形态不典型（切开、榨汁、树上、远处堆）
- 1-3 分：基本不是橙子（青柠/柚子/只有树/只有叶子/场景/人物/黑白/插画）

**必须剔除的低分图**：干橙皮丝、橙汁饮料、橙片鸡尾酒装饰、黑白橙园老照片、碗里橙黄色液体、剥开的橙皮。

## 五、平台使用注意

1. **上传控件依赖用户手势**——页面必须在前台可见，标签切到后台会导致上传失败
2. 新建项目或清空操作后，**刷新一次页面**再上传
3. 训练台每类样本上限 **100 张**
4. 提交纪律：可多次提交，以截止前最后一次为准；**最后一次若损坏/类别错/格式不符，按 0 分取代前次有效模型**；同分时早提交者优先
