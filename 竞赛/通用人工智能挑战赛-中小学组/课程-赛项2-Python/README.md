# 赛项2「识物工坊」全真备赛营 · 课程总纲

> **这是一门"打比赛"的课，不是一门"学Python"的课。**
> 赛制：初赛线上提交模型 ZIP（6.15–9.20 窗口，9.25 公示），决赛线下沙盘（识物工坊只在初赛计分，占 25/100）。
> 训练台底层是**迁移学习微调**（MobileNet 式底座+微调头部）：参数几乎不用动，
> **比赛的胜负手 = 采样质量 + 误判迭代**。故本营按比赛真实流程组织，
> 每讲对应一段比赛动作，Python 只是备赛工具。

---

## 一、比赛真实流程（官方手册）

```
初赛窗口内：注册报名 → 进入 /workshop/ → 采样（自拍橙子+难例非橙子）
  → 数据健康度检查 → 浏览器内训练（默认参数）→ 摄像头/新图测试
  → 误判分析 → 补难例 → 重训（迭代 N 轮）→ 导出模型 ZIP（≤2MiB）
  → 提交 /workshop/competition（以最后一次为准）→ 保密测试集计分
```

三条铁律（手册原文）：
1. **每类至少 5 张，建议 20+ 张**，覆盖角度/远近/明暗/背景/遮挡变化
2. **测试图绝不进训练**（防数据泄漏，否则自测分虚高、保密测试集露馅）
3. **备份**：模型 ZIP + 含图片的项目，每天导出（数据只存在本机浏览器）

## 二、备赛营玩法：五讲吃掉整场比赛

### 第1讲 · 领装备与采样大作战

拆解官方手册画作战地图 → **开战首胜：30分钟用现成素材练出第一个模型**（先跑通"上传→训练→测试"，体会网图与实拍分布差异）→ Python 速成 → 懂训练台的眼睛（附篇）→ **限时采样大作战**：两类各 20 张，健康度互查计分（附篇：数据整理工具箱）。

### 第2讲 · 训练一——第一枪

第1讲采的图正式上战场：上传 → 训练（默认参数）→ 测试 → **记录自测分与每张误判图**。误判按假阳/假阴分堆，留作下讲弹药。（附篇：像素世界 / 训练台原理）

### 第3讲 · 训练二——照方抓药

针对误判两堆补图：假阳多补相似非橙、假阴多补光线橙 → 重训 → **同一测试集**对比提升幅度。

### 第4讲 · 训练三——冲刺与一锤定音

最后一轮补刀 → 练"保守 vs 冒险"的提交决策 → **只许交一次**的定妆纪律 → 留档仪式（ZIP+备份+回执）。

### 第5讲 · 备赛准备——上正式考场前

赛前检查清单逐项过 → 正式提交全流程彩排（掐表 15 分钟内）→ 素材红线（学生必须自采图）→ 结营。

**训练占三讲（第2/3/4讲）**——比赛就赢在"训练-测试-归档-补图-重训"循环的轮次与质量。

## 三、与传统课程大纲的关键区别

| 旧思路（已弃） | 新思路（本营） |
|:--------------|:--------------|
| "学 Python 顺便备赛" | "打比赛，Python 是工具" |
| 网络找图/开源数据集喂训练台 | **必须自采**：保密测试集对的是真实拍摄分布，网图分布对不上 |
| 逐讲讲知识点，最后才上平台 | **第2讲就上平台**，多轮训练吃满课时，原理拆成附篇随用随讲 |
| 只讲训练 | 讲完整闭环：采样→训练→误判→补图→重训→提交纪律 |

## 四、教师须知

- **平台**：`/workshop/`（训练台）与 `/workshop/competition`（提交），数据存本机浏览器——机房电脑还原卡会清数据，**每课结束时导出项目备份是硬要求**
- **参数**：批大小 16、学习率 0.001 全程默认（迁移学习微调，动参数收益≈0）
- **质检不可省**：网络图源噪声率 ~1/3，学生自拍同样会混入错图——第3讲的健康度检查是得分的生命线
- **教师演示素材**：`测试素材/`（55+60 张，含 Wikimedia 拉取的 `wm_*`）供课堂投影/实验用；学生比赛须自采
- 环境配置见 `教师上手指南.md`
