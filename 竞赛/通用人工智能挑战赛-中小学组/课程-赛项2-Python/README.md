# 赛项2「识物工坊·橙子二分类」Python 备赛课程

> 本课程为「通用人工智能挑战赛·中小学组」赛项二（识物工坊·橙子二分类）的 Python 备赛课。
> 学生用 Python 的核心场景：**数据准备**（批量采集/整理/检查橙子、非橙子图片）+ **理解图像分类概念**（为浏览器内训练打好认知基础）。

---

## 一、课程定位

识物工坊用**浏览器内训练台**做二分类（橙子/非橙子），选手不写训练代码。但备赛需 Python 三件事：

① **数据准备**——用 Python 批量采集、命名、整理、去重、检查两类图片（决定模型上限）。
② **概念理解**——图像=像素矩阵、RGB、二分类、训练/测试集、模型评估（混淆矩阵/准确率/假阳性假阴性）。
③ **可选进阶**——用 Python（sklearn/Pillow）复现一个图像二分类，彻底理解训练台背后原理，优化样本策略。

> 学完本课程，学生能：自己用 Python 备好高质量橙子/非橙子数据集，并在训练台里调出更高分的模型。

---

## 二、课程结构（6 讲）

### 第1讲 · Python 起步（备赛地基）
| 知识点 | 赛项2用途 |
|:------|:--------|
| 变量、类型、input/print | 写数据准备脚本的基础 |
| 列表、字典、for 循环 | 批量遍历图片文件、统计样本 |
| 条件判断 if/else | 按类别分配图片、去重判断 |
| 函数 | 把采集/清理/检查封装成可复用流程 |
| 文件路径（os） | 定位图片目录、批量读文件名 |

### 第2讲 · 图片与像素
| 知识点 | 赛项2用途 |
|:------|:--------|
| 图像=像素矩阵 | 理解"整图二分类"到底在分类什么 |
| RGB / 颜色通道 | 看懂橙子(橙色调)与非橙子的区别 |
| PIL(Pillow) 读图 | 用代码读取、查看、保存图片 |
| 图片尺寸/格式 | 了解 JPG/PNG/WebP、15MB 限制 |

### 第3讲 · 批量数据准备（备赛核心）
| 知识点 | 赛项2用途 |
|:------|:--------|
| os 遍历文件夹 | 批量读取橙子/非橙子全部图片 |
| 批量重命名 | 给图片统一命名，便于管理 |
| 去重（哈希/相似度） | 避免大量几乎相同的连拍"背答案" |
| 按比例划分训练/测试集 | 保留从未训练的测试图，防数据泄漏 |
| 统计数量/检查健康度 | 保证两类数量接近、类别清晰 |

### 第4讲 · 机器学习与二分类概念
| 知识点 | 赛项2用途 |
|:------|:--------|
| 分类 vs 回归 | 理解"橙子/非橙子"是二分类任务 |
| 训练集/验证集/测试集 | 对应训练台的数据划分 |
| 特征/样本/标签 | 图像=样本，橙子+1/非橙子-1=标签 |
| 批大小、学习率 | 对应训练台的默认参数（16、0.001） |
| 数据健康度 | 处理重复/模糊/类别错误图片 |

### 第5讲 · 模型评估与优化（拿高分关键）
| 知识点 | 赛项2用途 |
|:------|:--------|
| 混淆矩阵 | 假阳性/假阴性分类——优化样本的抓手 |
| 准确率、召回率 | 衡量模型对橙子的识别能力 |
| 误判分析 | 假阳性多→补相似非橙子；假阴性多→补不同光线橙子 |
| 迭代训练-测试循环 | 用同一保留测试集比较前后模型 |

### 第6讲 · 进阶：用 Python 复现二分类（可选）
| 知识点 | 赛项2用途 |
|:------|:--------|
| sklearn 图像二分类 | 完整复现训练台背后流程，彻底理解 |
| 特征提取 + 简单模型 | 用颜色/灰度统计做最简单的橙子分类 |
| 对比 Python 与训练台 | 懂原理后，更好地在上训练台调参 |
| 数据增强思想 | 旋转/亮度变化增多样本，提升泛化 |
