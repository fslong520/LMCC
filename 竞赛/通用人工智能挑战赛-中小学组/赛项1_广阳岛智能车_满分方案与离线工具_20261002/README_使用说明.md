## 一、这是什么

2026 全国通用人工智能挑战赛 · 中小学组，**赛题一「广阳岛智能车」**（75 分）的完整成果，分两部分：

1. **可直接上平台运行的参赛代码**——三个综合任务的满分脚本；
2. **离线路线优化工具链**——在自己电脑上重放、评分、重新生成路线的全套程序，
   不联网、不依赖比赛平台，可用来讲解方法、排查问题、给学生做二次实验。

赛题二「识物工坊」的成果是另一个包（`赛项2_识物工坊_最好结果与训练集.zip`），不在本包内。

### 成绩一览（均为离线重放实测）

| 任务 | 基线（云端记录） | 本包最优 | 用时 | 效率满分线 |
|---|---|---|---|---|
| 任务1 | 100 分 | **100 分** | — | — |
| 任务2 | 98.2 分 / 165.0 s | **100 分 / 120.0 s** | 120.0 s | 124.8 s |

## 四、离线工具链怎么跑

以下命令全部在 `2_离线工具链/` 目录内执行（先 `cd 2_离线工具链`）。

### 1. 重放任务3满分路线

```bash
node tools/replay.js routes/candidates/T3_v7.py
```

实测输出：`"score": 100`，`"durationSeconds": 195.2`，`"completed": "18/18"`。

### 2. 重放任务3基线（对照）

```bash
node tools/replay.js routes/baseline/T3_baseline_98.0.py
```

实测输出：`"score": 98`，`"durationSeconds": 210.5`。

### 3. 重放任务2满分路线

任务2 数据在 `data2/`，**必须用环境变量指定**，否则读成任务3的数据：

```bash
GY_DATA_DIR=data2 GY_FULL=full_task2.json GY_AUTH=auth_scene.json \
  node tools2/replay2.js routes2/candidates/T2_ord29_best_100_119.9s.py
```

实测输出：`"score": 100`，`"durationSeconds": 120`，`"completed": "13/13"`。

### 4. 重放任务2基线（对照）

```bash
GY_DATA_DIR=data2 GY_FULL=full_task2.json GY_AUTH=auth_scene.json \
  node tools2/replay2.js routes2/baseline/T2_baseline_98.2.py
```

实测输出：`"score": 98.2`，`"durationSeconds": 165`。

### 5. 重新生成一条任务3路线（约 3 秒）

```bash
cd tools
node --max-old-space-size=6144 generate3.js --out ../routes/candidates/T3_regen.py
cd ..
node tools/replay.js routes/candidates/T3_regen.py
```

实测：生成 114 条指令、估算 195.96 s，与满分路线 `T3_v7.py` **逐字节一致**，重放 100 分。
换地图/改锚点后可重复此流程。

### 6. 用真机记录校验时长模型

```bash
node tools/verify_timing.js routes/baseline/T3_baseline_98.0.py ../3_真机校验数据/real_inputs.json
```

实测输出：「比对 179 条：完全一致 164 条（91.6%）」，转向步累计偏差 `-4.3e-14` tick，行驶步 0 tick，
判定「零散偏差，无系统性附加耗时」。

## 六、六个坑（都踩过，务必看）

1. **`routes/candidates/T3_best_100.py` 不要用于提交，也不要用于演示。**
   它含一条 `left_angle(0.3429)` 的微角度转向，平台前端校验要求转向角 ≥ 1°，
   离线重放器同样会直接报错 `line 69: 转向角度必须在 1 到 360 度之间`。
   **任务3 请用 `routes/candidates/T3_v7.py`**（= 包里 `1_参赛代码_三任务/任务3_满分_100分_195.2秒.py`）。
   v1–v5 也都有同类微角度问题，属已修正的历史迭代，仅作记录。

2. **任务2 的三个环境变量一个都不能少**（见第四节第 3 条）。
   漏掉会读到任务3的场景，重放结果变成 23.9 分且满屏「被拒交互」——
   这不是路线坏了，是数据目录读错了。

3. **`data/`、`data2/`、`tools/core.js`、`tools/vision-pixel-core.js` 是平台定义与内核的副本，绝对不要改。**
   改了以后所有重放结论作废，且很难察觉。

4. **障碍物只存在于 `auth.inter.packages`，`auth.packages` 只有 6 个包裹、不含 3 个障碍物。**
   自己写脚本时用错数据源会漏判碰撞——本项目曾因此连续失败两版（v1、v2）。

5. **任务1 没有离线数据，无法在本地重放。**
   本包只提供代码（任务1 走 `observe` / `follow_road`，重放器也不支持这些指令）。
   任务1 请直接在平台验证；其满分成绩以平台记录为准。

6. **原备份里 `任务1_当前工作区_满分版.py` 是「一行含字面 `\n` 的字符串」，
   直接粘贴到平台会变成一行废字符串。**
   本包 `1_参赛代码_三任务/任务1_满分_100.py` 已还原成 55 行正常代码，用它即可；
   `历史备份/` 里保留了原件。

## 七、常见问题

**Q：跑命令报 `Cannot find module` 或 `ENOENT`？**
多半是在错误的目录执行。先进 `2_离线工具链/`，命令里的 `tools/`、`routes/` 都相对它。

**Q：Windows 下 `GY_DATA_DIR=data2 node ...` 不生效？**
Windows CMD/PowerShell 的环境变量写法不同。PowerShell：
`$env:GY_DATA_DIR='data2'; $env:GY_FULL='full_task2.json'; $env:GY_AUTH='auth_scene.json'; node tools2/replay2.js routes2/candidates/T2_ord29_best_100_119.9s.py`

**Q：`generate3.js` 内存不足？**
必须带 `--max-old-space-size=6144`（命令里已带）。机器内存不足 8G 时可尝试降到 4096。

**Q：重放 100 分，为什么平台跑出来不是？**
平台的地图变体、包裹位置可能与本包数据不同（改包裹位置需管理员权限）。
换图后需重新导出场景数据，再走「生成 → 重放」流程。

**Q：想给学生讲原理，从哪看起？**
先 `2_离线工具链/README.md`（核心发现与时长模型，篇幅短、结论硬），
再 `docs/task2-findings.md`（任务2 的约束与下界分析），最后 `docs/task2-round2.md`（七轮迭代全过程）。

## 八、方法一句话概括

把「沿路网折线逐节点绕行」改为「道路走廊内直线行驶」：
可行域是**走廊并集**而非路网折线（基线绕行比 1.45）；
转向耗时正比于角度且转向期间零位移，是纯损耗；
抓放位姿冻结、只重算锚点之间的路径；用 Dijkstra 在 `(节点, 进入来源)` 状态上以
`转角代价 + 直行代价` 求 tick 最优解。任务2 再叠加「包裹处理顺序重排」——
最优顺序比基线省 27 单位直线距离，这是任务2 能从 98.2 冲到 100 的主因。

更细的公式、约束与证据见 `2_离线工具链/README.md`。
