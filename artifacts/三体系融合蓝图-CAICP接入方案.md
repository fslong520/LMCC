## 二、计算思维落点建议（无落点 → 增课 vs 并课）

### 2.1 现状：确无落点

CAICP 计算思维四类典型题（`竞赛/caicp/README.md:24`、`:59`）：**赛制逻辑推理、图形规则推导、基础算法推演、抽象建模**。全仓检索：

- `grep -rn "计算思维" --include=*.md --include=*.typ .` 仅命中 `课堂自查清单.md:80,91`（信息学移植表，非本体系课程）与 CAICP README 本身；
- `grep -rn "赛制推理\|图形推导\|算法推演\|抽象建模"` 仅命中 CAICP README；
- 现有最接近者：`LV1-02` 的"四块语法读码填行号"（`lv1/readme.md:43`）——是**代码阅读**，非抽象建模；`LV5-01 NOAI全景-赛制/题型/真题巡礼`（`LMCC课程大纲.typ:302`）讲**NOAI** 赛制，非 CAICP 赛制推理题。

**结论：计算思维在现五级中零落点，属真缺口。**

### 2.2 方案 A：独立成课

**做法**：LV1 增设"计算思维"专题课（或 LV2 增设"抽象建模"课），系统讲四类题型。

| 利 | 弊 |
|:---|:---|
| 知识成体系，四类题型一次讲透，便于出题与测评 | **破 110 课时总量**——`融合课程体系.md:98` 与 `README.md:21` 均以"合计 110"为口径，加课须同步改 .typ、README、项目企划书、融合体系，牵动面最大 |
| 与 CAICP 官方大纲一一对应，宣传上"三维度全覆盖"最直观 | LV1 已是双螺旋高密度层（每课"用AI+学Python+加项目"，`融合课程体系.md:108`），再插纯思维课打断"做 Agent"主线 |
| 教研可独立开发，不挤压现有课备课 | 计算思维多数题"不需编程、更似逻辑推理"（`竞赛/caicp/README.md:24`），单独成课动手占比难达 `课堂自查清单.md` 所要求的 ≥50% 学生活动 |

### 2.3 方案 B：并入现有课

**做法**：不加课时，把四类题型拆到现有课的环节里 + LV5 真题课单练。

| 利 | 弊 |
|:---|:---|
| 零课时成本，守住 110 口径 | 单课时内三段式已满，挤占原环节，存在"贴标签"风险（`课堂自查清单.md:80` 明警"别把素养当标签贴"） |
| 与"统驭工程"主轴同构：抽象建模＝提需求/定约束的前置，赛制推理＝验结果的变体，可直接挂 `统驭能力进阶表.md:33-40` 的的①②③④段 | 分散四处，学生难以形成"这是 CAICP 计算思维"的整体认知，备考时需二次汇总 |
| LV5-10/11 本就是真题模拟课（`LMCC课程大纲.typ:311-312`），天然承载赛制推理与图形推导的集中训练 | 依赖教师自觉执行，无独立教案则易漏（现 77 份教案 0 处 NOAI/CAICP 标注即为前车之鉴） |

### 2.4 推荐：**并入现有课为主、LV5 真题中单练为辅**（与首辅裁断三一致）

**依据**：
1. **课时硬约束**——体系已 110 课时且三处目录尚未对齐，此时加课会把口径混乱从 2 处扩大到 4 处（.typ/README/融合体系/企划书）；
