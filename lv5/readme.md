# LV5 冲NOAI·算法冲刺篇

## 概述

本级别是双体系融合后新增的**冲奖冲刺层**——专门面向要冲击 NOAI（人工智能奥林匹克）的学员，强化机器学习建模、深度学习建模、数学重难点与真题实战。

> **设计逻辑**：LV0-LV4 打好了 AI 认知、Python、ML/DL 原理基础，本级别把它们落成 NOAI 竞赛所需的硬实力——初赛的理论应试 + 复赛的上机建模。学完本级别，即可自信报名 NOAI。

## 前置要求

- 建议先后完成 LV0 筑基（会 Python）、LV2 懂原理（懂 ML/DL）
- 需具备一定的 Python 编程与数学基础

## 学习目标

完成本级别学习后，学员应能：

1. 用 sklearn 完成分类/回归建模与调参（复赛题型B）
2. 用 PyTorch 手写 CNN 完成图像分类，会算特征图尺寸（复赛题型C）
3. 用 pandas 做数据清洗与探索可视化（复赛题型A）
4. 强化概率统计、线性代数、微积分核心重难点（初赛 E区）
5. 完成端到端 AI 建模综合项目（复赛收官）
6. 熟悉 NOAI 初赛（纸笔）与复赛（上机）真题，从容应试
