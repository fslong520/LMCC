## 目标

我们让她把 AI 从"讲给她听"改成"考她"，三类活各用一句能照抄的话，最后她拿一条真错题走完一轮，再用 OpenMAIC 生成一节课。

## 全场骨架

```
〇 开场            6 ── 问她"它讲完你没听懂，你怎么知道"，记下不纠正
一 三类用处       10 ── AI 做什么、她做什么；写一句"它看不到我怎么想"
二 四件事         12 ── 身份、任务、边界、验收；重点边界与验收
三 讲概念         16 ── 它讲 → 她手写 50 字 → 它只挑错 → 只考那一点
四 出题           18 ── 四项要求 → 查答案印没印 → 答 8 题带理由 → 只要对错
五 错题分析       18 ── 说清当时怎么算 → 三条原因 → 她挑一条 → 只讲那条 → 再考
六 OpenMAIC       20 ── 是什么、入口与访问码、课堂里有什么、六步操作、生成一节记三条收获
七 当堂练习       12 ── 四道，巡看要求原文与"当时的想法"
八 保存与作业      8 ── 05-学习教练.md ＋ 作业口径
```

合计 6+10+12+16+18+18+20+12+8＝120 分钟。

**超时预警**：第四节 18 分钟最容易超，到点必收，剩一半题留到第七节做；六节若卡在取码，按讲义 7.4 顺延到下次课。

## 三个要交代清楚的地方

1. 复述她手写。这里必须要她手写，这是因为他只会照自己那套话写，也就是说，让她复述等于又听一遍；如果她写不出来，那么换她自己举的例子重讲一次，不许让 AI 代写。
2. 出题时答案要留住。这里必须要求写清答案什么时候给，这是因为他会把 8 道题的答案印在每道题下面；如果漏了这一项，那么这组题作废重出。
3. 错题先要原因，不要先讲知识点。这里必须要求它先给三条原因，这是因为他会从定义讲到规则；如果她不先说这一句，那么它直接开讲，那条错题就白做。

## 她的常见卡点与应对

| 卡点 | 应对 |
|:---|:---|
| 复述写不出，想抄 AI 的 | 给半个句式让她补："负数乘负数，可以理解成转两次身……"；还不行就换例子重讲 |
| AI 讲太长、跑题 | 教她发"超过 200 字了，重讲，只留三句" |
| 出题时答案印出来了 | 作废重出，原话后加"答案放最后，我回一句'开始'你再发" |
| 觉得"这些我都会，不用考" | 当场答 3 道，错一道就够；一道不错就走 B 路，写别人会怎么错 |
| 三条原因写成知识点 | 加一句"不要写知识点，写我当时可能怎么想的，用'我把它当成了……'开头" |
| 挑不出哪条原因像自己 | 让她把当时的算路一步步写下来，写到第二步常就看见了 |
| 再考又错 | 回第二步重新挑原因，最多三次；三次不行就换更简单的同类题，记录卡在第几处 |
| 判分后只想看错题 | 这是设计：先只要对错，就是为了让她读得进那一两道 |
| OpenMAIC 没有访问码 | 请家长在 open.maic.chat 注册取码；当堂先做 7.1~7.3，7.4 留到下次课 |
| OpenMAIC 生成失败 | 换材料或换主题再生成；仍不行就记下现象，课上不硬耗，把三条收获改成"记下卡在哪一步" |

## 三句原文速查（照念）

| 场景 | 一句 |
|:---|:---|
| 讲概念 | 你是我初一的数学老师。给我讲清（概念）。用（例子）当例子。200 字内，别一开头写公式。讲完出 3 道小题考我，先不给答案。 |
| 只挑错 | 这是我用自己的话复述的：『……』。只找说得不对和不清楚的地方，一句一句指出来。不要替我重写。 |
| 出题 | 四项：①范围只考（…）②3 简单 4 中等 1 易错 ③全单选、四选项、其中一个是常见错误答案 ④先只给题目，答案留着，我说"我答完了"再给。 |
| 交卷 | 我答完了：1（ ）2（ ）…… 每题写了为什么这么选。先只判对错，不给解析。 |
| 错题 | 我选 B，正确答案 C。题干（…）。我当时想的是（…）。先别讲知识点，给我三条错的原因，按可能性排序，我先挑。 |
| 只讲一条 | 第 2 条对。就按这条讲，100 字内，别把整套规则讲一遍。 |
| 再考 | 出一道只考这一点的同类型题，先给题不给答案。 |
