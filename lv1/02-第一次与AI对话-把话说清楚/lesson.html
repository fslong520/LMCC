5.1 收话：程序停下来等你（2 分钟）

name = input("给这一生起个名字：")

程序停在这行等你敲字，你一回车，你敲的东西就进了 name。它收下来的永远是文字，你敲 20，它收到的是「20」两个字。

5.2 换牌：文字变数字（2 分钟）

wits = int(input("智力加几点："))
pick = int(input("输编号："))

int() 把文字换成数字。换不动就报 ValueError，1.3 见过；换得动但值不在范围里，后面还要出事，3.1 见过。

5.3 分支：程序做选择（2 分钟）

if wits >= 40 and body < 25:
    print("结局：学霸，课间都在补觉")
elif wits >= 25 or body >= 25:
    print("结局：普通，但有一样拿得出手")
else:
    print("结局：平平无奇，下辈子再练")

条件能连着用（and、or），档就能一层层往下分，最后 else 兜底。冒号下面缩进四格，缩错了当场红字。你在 4.1 设计的那几档结局，用的就是这一套。

第四步　写 Python。先看样例输入：02-G 的样例是 2 3 5，一行三个数，空格分开。这就是输入的第一个坑：写成三次 int(input())，第一次拿到的是「2 3 5」一整行，转换就崩。一行几个数，就一次读进来再拆开：

# 02-G：一行三个数
a, b, c = map(int, input().split())
print(a + b + c)

# 02-H：一行两个数，换个位置输出
a, b = map(int, input().split())
print(b, a)

拆开讲：input() 收一整行，split() 按空格拆成好几个词，map(int, …) 把每个词换成数字，几个变量一次接住。样例里一个数占一行的题，才写 int(input())。看样例输入长什么样，决定你怎么写，这句话记牢。
