# LV1 人工智能与AI基础（基础素养篇）

## 概述

本级别面向零基础学员，系统介绍人工智能的基本概念、发展历史、核心技术和应用领域，帮助学员建立对AI和大模型的整体认知，为后续深入学习打下坚实基础。

## 前置要求

无编程基础要求，具备基本计算机操作能力即可。

## LMCC对标说明

本级别对应LMCC第一轮考试中"大模型基本素养和概念类知识"部分的核心内容，涵盖人工智能基础概念、机器学习与深度学习原理、大模型发展与应用、提示词工程、编程入门及认证体系认知等知识模块。

## 学习目标

完成本级别学习后，学员应能：

1. 理解人工智能的定义、发展历程及核心驱动力
2. 识别AI技术在各行业中的典型应用场景
3. 区分监督学习、无监督学习和强化学习的基本范式
4. 掌握机器学习经典模型（线性回归、决策树、KNN、SVM）的核心思想
5. 理解神经网络与深度学习的基本原理（感知机、反向传播）
6. 了解自然语言处理的发展脉络及关键技术
7. 描述大模型从统计语言模型到LLM的演进路径
8. 运用提示词工程基础方法（角色设定、Few-shot、CoT）提升模型输出质量
9. 通过API调用大模型，构建简单对话应用
10. 掌握Python基础语法，完成简单的数据处理任务
11. 了解LMCC认证体系、考试形式与备考策略

## 教学建议

1. **重直观，轻公式**：零基础学员对数学符号有畏难情绪，概念讲解优先使用类比、图示和实物演示，避免过早引入公式推导。例如用"猜价格"解释线性回归，用"分水果"解释决策树。

2. **每课必有动手环节**：每节课至少安排一次动手实践，哪怕是"打开一个AI工具体验一下"也算。第11课之后的编程环节建议使用在线Notebook环境，降低环境配置门槛。

3. **大模型贯穿始终**：从第1课就让学员接触真实AI工具（如ChatGPT、通义千问），在后续课程中反复用大模型辅助理解、演示概念，形成"用AI学AI"的沉浸式体验。

4. **项目驱动收尾**：第19课的项目（AI聊天机器人）应提前铺垫，从第11课起逐步积累API调用和Prompt设计的经验，最终集成一个完整作品，增强成就感。

5. **关注认证但不唯认证**：LMCC认证考点作为内容组织线索，但教学中应注重理解而非应试。第16-17课集中梳理考点，考前配合模拟题训练即可。
