# LV1 会用AI（应用体验篇）

## 概述

本级别是整个LMCC课程的起点，核心理念是**"先玩起来"**——不讲公式、不摆推导，直接从"用AI"开始。学员将在一系列真实场景中（写作、学习、绘画、办公、翻译、数据……）动手使用AI工具，建立信心、激发兴趣，并掌握提示词基本功与信息甄别意识。

> **唯一的例外是第 03 课**：前两课学生已确认"大模型很能干"，第 03 课插一节**理论课**——大模型的工作原理五件套，要求记和背（讲义有背诵点框＋闭卷默写＋课末小测）。原理讲的仍是学生前两课刚用过的东西（接话、切自己写的句子、猜半句话的下文），不做数学、不讲算法；每个理论点后面都配一个当堂动手动作，学生活动仍占 78%。LV2 会把这五件事各拆成一整课展开。

> **设计逻辑**：先让学员"会用、敢用、爱用"，把AI变成日常工具；有了切身体验作为锚点，后续LV2的原理学习才有抓手、不枯燥。

## 前置要求

- 无任何技术基础要求，会打字、会上网即可
- 不需要编程基础，不需要数学基础

## 学习目标

完成本级别学习后，学员应能：

1. 说出AI在生活中的常见应用，建立"AI无处不在"的感知；能判断一件东西"算不算AI"
2. **遵守AI使用三条约定：AI不能代替我学习；我先学会，再让AI去做重复枯燥的活；我必须能自己分辨对错**——且能各举自己的例子
3. 独立完成与AI的第一次有效对话，把需求说清楚
4. 掌握提示词三要素（角色、任务、要求），写出合格的提示词
5. 在写作、学习、绘画、办公、翻译、总结、数据等场景中熟练调用AI提效
6. 使用进阶提示技巧（示例、分步、追问）提升AI输出质量
7. 认识主流AI工具的分类地图（文字/图像/视频/音频）
8. 体验多模态AI（语音、图像、视频）的交互方式
9. 对AI的回答保持警惕，掌握基本的事实核查方法
10. 描述AI的常见局限（幻觉、偏见），不盲目相信AI
11. 用AI辅助学习新知识，形成"用AI学AI"的习惯
12. 独立完成一个"用AI完成真实任务"的综合实战
13. 整理出属于自己的AI工具清单与使用心得

## LMCC考纲对标

本级别对应LMCC考纲第一轮"提示工程"（考点15）的应用体验层，并以真实场景为"大模型的超能力"（考点4）、"模型评测与伦理安全"（考点20/21）、"多模态模型"（考点22）积累直观体验，为后续级别埋下认知锚点。考点全覆盖对照见各课教学大纲"对应LMCC考点"列。

## 教学建议

1. **每课必动手**：本级别不安排纯理论课，每节课至少一半时间让学员亲手使用AI工具。宁可演示少一点，不可动手少一分。

2. **工具前置准备**：本课程统一用 **WorkBuddy**（腾讯桌面智能体，Win/Mac/Linux 安装即用，微信扫码登录，免费额度可覆盖课堂）。**开课前必须装好并登录好，课上装会吃掉十几分钟。** 备用路径：机器出问题时改用手机上的 AI App（豆包／文心等），四轮任务要求不变。

2b. **任务链而非单任务**：一堂课要串三到四个任务，**前一轮的产出是后一轮的原料**（如第1课：查→表→做→海报→挑错→重做）。单任务串到底，学生只觉得"在用工具"；任务链递进，每轮都要多会一点，才能贯穿下来。

3. **对比教学**：鼓励学员用同一个问题问不同工具、不同模型，对比回答差异——这既练习提示词，也为LV2的"模型家族"埋下伏笔。

4. **错误也是教材**：AI答错、答偏、编造，都是绝佳的教学契机。第14-15课专门讲甄别与局限，但前面的课中遇到"AI胡说"也应随时停下来讨论。

5. **项目驱动收尾**：第17课综合实战应提前铺垫，从第4课起每次场景课都提示"这个技能将在综合实战中用上"，最终让学员完成一个完整的、属于自己的AI作品。

6. **趣味优先**：写作、画画、翻译等场景选择贴近学员生活的话题（作文、表情包、游戏攻略、流行文化），兴趣是最好的老师。

7. **三条约定**：第1课在"抓错"环节之后自然带出三条——**AI不能代替我学习；我先学会，再让AI去做重复枯燥的活；我必须能自己分辨对错**。不搞签名仪式，改为**课后作业末尾写一行"哪部分是我自己做的、哪部分是AI帮我做的、我怎么检查的"，写不出不算完成**。约定要有实据才立得住，学生刚亲手抓到AI的错时讲，比单独宣读有效。

8. **判断先于记忆**：讲"什么是AI"不要只给定义。第1课已改为让学生先判断"扫地机、计算器、导航、相册分组、语音助手、自动门哪些算AI"，再用定义回推——**判断的标准是"它是不是自己从数据里学会的"**。此处不可省，否则LV2讲原理时学生没有可挂的锚。

9. **统驭显名**：第1课即点破本课程核心是**统驭 AI**（说清需求→动手试→挑错→改一版），此后每课都要问一句"这一课练的是统驭哪一段"。统驭四段工序、四级八段进阶与逐段验收证据见 `../统驭能力进阶表.md`。LV1 主练①提需求、②初阶验结果两段。
