# LV1 会用AI（应用体验篇）

## 概述

本级别是整个LMCC课程的起点，核心理念是**"先玩起来"**——不讲理论、不摆公式，直接从"用AI"开始。学员将在一系列真实场景中（写作、学习、绘画、办公、翻译、数据……）动手使用AI工具，建立信心、激发兴趣，并掌握提示词基本功与信息甄别意识。

> **设计逻辑**：先让学员"会用、敢用、爱用"，把AI变成日常工具；有了切身体验作为锚点，后续LV2的原理学习才有抓手、不枯燥。

## 前置要求

- 无任何技术基础要求，会打字、会上网即可
- 不需要编程基础，不需要数学基础

## 学习目标

完成本级别学习后，学员应能：

1. 说出AI在生活中的常见应用，建立"AI无处不在"的感知
2. 独立完成与AI的第一次有效对话，把需求说清楚
3. 掌握提示词三要素（角色、任务、要求），写出合格的提示词
4. 在写作、学习、绘画、办公、翻译、总结、数据等场景中熟练调用AI提效
5. 使用进阶提示技巧（示例、分步、追问）提升AI输出质量
6. 认识主流AI工具的分类地图（文字/图像/视频/音频）
7. 体验多模态AI（语音、图像、视频）的交互方式
8. 对AI的回答保持警惕，掌握基本的事实核查方法
9. 描述AI的常见局限（幻觉、偏见），不盲目相信AI
10. 用AI辅助学习新知识，形成"用AI学AI"的习惯
11. 独立完成一个"用AI完成真实任务"的综合实战
12. 整理出属于自己的AI工具清单与使用心得

## LMCC考纲对标

本级别对应LMCC考纲第一轮"提示工程"（考点15）的应用体验层，并以真实场景为"大模型的超能力"（考点4）、"模型评测与伦理安全"（考点20/21）、"多模态模型"（考点22）积累直观体验，为后续级别埋下认知锚点。考点全覆盖对照见各课教学大纲"对应LMCC考点"列。

## 教学建议

1. **每课必动手**：本级别不安排纯理论课，每节课至少一半时间让学员亲手使用AI工具。宁可演示少一点，不可动手少一分。

2. **工具前置准备**：开课前确认学员可用的AI工具（网页版/手机App），提前注册账号。若网络环境受限，优先选用国内可直连的工具。

3. **对比教学**：鼓励学员用同一个问题问不同工具、不同模型，对比回答差异——这既练习提示词，也为LV2的"模型家族"埋下伏笔。

4. **错误也是教材**：AI答错、答偏、编造，都是绝佳的教学契机。第14-15课专门讲甄别与局限，但前面的课中遇到"AI胡说"也应随时停下来讨论。

5. **项目驱动收尾**：第17课综合实战应提前铺垫，从第4课起每次场景课都提示"这个技能将在综合实战中用上"，最终让学员完成一个完整的、属于自己的AI作品。

6. **趣味优先**：写作、画画、翻译等场景选择贴近学员生活的话题（作文、表情包、游戏攻略、流行文化），兴趣是最好的老师。
