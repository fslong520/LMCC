## 课末小测答案（第八节 14 题）

1. 块（Token）　2. 预测下一个块　3. 1 到 2　4. 上下文窗口　5. 预训练 → 指令微调 → 人类对齐　6. 对　7. 错（它按最像的往下补，不是查资料，编出来的叫幻觉）　8. 错（块数有上限）　9. 对　10. ②（词表最长匹配）

11. ②（查词表取块）　12. ①（数字坐标）　13. ②（生成一个结束块）　14. ①（回头看上文，谁更该看就多看谁）

11 题以上算过；第 5、10 题允许错。前 11 题必做，12 到 14 题做不完转作业。

## 一句话目标

记住并说得出大模型工作的五件事，让 AI 写一个分词器并读明白它用哪种算法，把切出来的块存进 Python 列表，走通「块 → 编号 → 文字／坐标 → 注意力 → 整段」这条链，再给上节课的网页接上 AI 编的事件与选择。

## 今天四件事

```
懂它凭什么  ── 五件事，每件都当场试一次、当场填一张卡（一~五节）
写个分词器  ── 让 AI 写，你读代码认算法，再把结果存成列表（二节，23 分钟）
链路四段    ── 编号变字 → 坐标 → 注意力 → 接成段并停下（3.4~3.7）
接上 AI     ── 网页里换事件表：AI 编 10 条事件，每条两个选择（七节，20 分钟）
```

**本课与前两节不同**：理论课，但学生活动约 78%。每件事先动手再讲解，倒过来讲就变成灌输。

## 五个必背点（口径统一，上课不要临场加数字）

| # | 学生要能默出来的一句 | 课上怎么说 |
|:--:|:---|:---|
| ① | AI 读的是切好的块，一块叫 Token；中文一个字常常切成 1 到 2 块 | 切法因模型而异，只考这个范围 |
| ② | 大模型的核心工作是预测下一个块，一次只猜一块，猜完接着猜 | 「猜」这个字要让学生说出口 |
| ③ | 它给每个候选按「像不像」排队，最像的排最前；有时取中间的，所以同一句问两遍不一样 | 不提概率、不提温度 |
| ④ | 参数是模型里的一大堆数字，越多装的经验越多；一次能看见的块数有上限，叫上下文窗口 | 参数＝脑子里的旋钮 |
| ⑤ | 训练三部曲是预训练、指令微调、人类对齐，顺序不能换 | 「从小读书→上班培训→师傅带」 |

**唯一允许出现的数字**：GPT-3 1750 亿参数（2020 年）、ChatGPT 2022 年 11 月发布。学生问「豆包和 ChatGPT 谁厉害」，答「比大小要看用什么题目考，第 15 课讲模型地图」。

## 链路四段（不进背诵卡，但要能复述）

| 段 | 一句话 | 常被问 |
|:---|:---|:---|
| 3.4 编号变回文字 | 猜的是编号，查词表取回那一块，接到后面 | 半个字＝两个编号拼一个字 |
| 3.5 块变成坐标 | 每块一串数字坐标，意思近坐标近 | 坐标是训练出来的，不是人贴的 |
| 3.6 注意力 | 算某一块时回头看同句别的块，谁更该看就多看谁 | 「它」指谁由「重／矮」定 |
| 3.7 收尾 | 碰到结束块就停；换行、分段也是块 | 同一句两遍长短不同，原因在这 |

## 三种切分算法（二节读代码的尺子）

| 算法 | 代码里看什么 | 切出来什么样 |
|:---|:---|:---|
| 按空格和标点切 | 找 `split`、`re.split` | 英文一词一块，中文整串不切 |
| 词表最长匹配 | 有表，循环里比长度，`len`、`startswith` | 表里的词整块，长词一次吃好几个字 |
| 一个字一块 | 只有 `for ch in text`，没有表 | 每字一块，块数等于字数 |

学生能指认一种并说出线索，这一节就算过。**不要求讲清最长匹配的实现细节。**

## 三个必须抓住的点

1. **先做后讲**。每节都是：让他先试、先猜、先跑，你后说。①先看 AI 接了什么，②先让 AI 写出来，③先写下三个猜的词，3.5 先自己摆坐标，3.6 先自己判断指谁。

2. **②要读代码，不止跑**。跑通不难，难在这一问：它靠什么决定在哪切？让学生指着代码说出「有一张表」「循环在这一行」。只跑不读，等于又给孩子一个黑盒。

3. **七节改的是数据，不是程序**。反复强调：AI 编的是 `const EVENTS` 里那段事件，页面那套代码一行没动。学生看懂这层，后面学 API 才不慌。

## 卡点与应对

| 卡点 | 应对 |
|:---|:---|
| AI 只打印不返回列表 | 补一句「返回列表，不要 print」；还不行就把 print 改成 return |
| 学生写 blocks[4] 报 IndexError | 回到 0 起算：四块是 0～3，先 print(len(blocks)) 再取 |
| AI 只写了按空格切，中文一大串 | 照常填卡，这是第一种算法；2.3 改成词表最长匹配，两版对比 |
| AI 写了一大套（自带词表、字节回退） | 只找三样：有没有表、循环在哪、表外怎么处理 |
| 分词器要装第三方库、跑不起来 | 让它改成只用标准库；仍不行投屏 `codes/05-分词器-学生版参考.py` |
| `04-分词机.py` 打开慢 | 首次要载词表，约 8 秒；先开好再投屏 |
| 学生分不清「块」和「词」 | 用 2.4 那句：模型按统计切，「天天」一块，「，我」也一块 |
| 3.6 争「它」指谁 | 让他看后面那个词（重／矮），再看回路图；到点就收 |
| 3.7 让它只答两个字，它不听 | 正好：说明停的条件受要求影响；要求写清楚它才照做 |
| 网页白屏 | F12 看红字；九成是逗号多了少了，或引号变成中文引号 |
| 事件贴进去不出现 | 检查是不是把 `];` 删了，或 `const EVENTS = [` 的方括号没配对 |
| 点了没反应 | `effect` 的键名只能是 wits、body、luck、money |
| AI 编的事件跟年代对不上 | 7.2 第一验，在要求里补「1990 年不能出现手机、二维码」 |
| 两个选项都是好处 | 7.2 第二验，要求里加「一个得一个失」 |
| 事件条数太少，18 年重复 | 当场再要一次：「一次 10 条，年龄区间写清楚」 |
| 第二课的网页丢了 | 用 `codes/03-接线版-事件与选择.html` 直接改 |
| 学生问「AI 是不是在查资料」 | 三节那个钩子：它按最像的补，猜错就叫幻觉，第 15 课拆 |
