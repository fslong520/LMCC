# LV4 思辨AI（素养未来篇）

## 概述

本级别是LMCC课程的收尾与升华。前三级别解决了"会用、懂理、会造"，本级别回答更高一层的问题：**"我们该如何与AI共处？"**

学员将系统思考AI带来的伦理、偏见、隐私、安全、版权、就业、教育、创造力、治理等议题，通过课堂讨论、辩论赛、研究报告等形式，培养AI时代最宝贵的**批判性思维与独立思考能力**，最终完成结业项目"我的AI研究报告"，为整个课程画上句号。

> **设计逻辑**：会用AI是技能，懂AI是知识，思辨AI是素养。通识教育的终点不是工具熟练度，而是培养负责任的AI公民。

## 前置要求

- 建议先完成LV1-LV3课程（已有"用AI、懂AI、造AI"的完整体验）
- 需要一定的资料检索、写作与表达能力（可在项目中指导提升）

## 学习目标

完成本级别学习后，学员应能：

1. 理解AI伦理的基本议题，对"技术有无对错"形成自己的判断
2. 识别算法偏见与数据偏见的成因，举出生活中的实例
3. 认识AI使用中的隐私与数据安全风险，保护个人信息
4. 描述AI安全风险（幻觉、越狱、提示注入、恶意滥用）及应对方法
5. 就AI生成内容的版权问题发表有依据的观点
6. 客观分析AI对就业市场的影响，理解人机协作关系
7. 形成AI时代的自主学习策略，不被技术淘汰
8. 思考AI与人类创造力的关系，理解"人机共创"的价值
9. 了解国内外AI治理与法规的基本框架
10. 识别深度伪造与信息茧房，具备AI时代媒体素养
11. 认识AI的能源与环境成本，形成可持续视角
12. 区分强人工智能（AGI）与当前AI，理性看待科幻叙事
13. 参与伦理辩论，有条理地表达与倾听不同观点
14. 探索AI时代的职业可能，规划个人发展方向
15. 制定并践行个人的AI使用守则
16. 独立完成"我的AI研究报告"（选题、研究、写作、答辩）
17. 串联整个课程（会用-懂-驾驭-思辨），形成完整AI素养体系

## LMCC考纲对标

本级别对应LMCC考纲第五章"模型评测与伦理安全及多模态"（考点20-21）的素养层与思辨层。其中"模型评测流程及指标"（考点20）的原理已在LV2-14覆盖、实践已在LV3-16/17落地，本级别专注"模型伦理与安全"（考点21）的深入探讨。第19课大回顾串联全部考点。考点对照见各课教学大纲"对应LMCC考点"列。

## 教学建议

1. **讨论优先于讲授**：本级别的核心教学法是讨论与辩论，而非单向讲授。每课设计开放性问题，鼓励学员发表观点、相互质疑，教师负责引导与追问。

2. **案例真实鲜活**：伦理、偏见、隐私等议题务必用真实案例（新闻事件、产品事故、社会争议）引入，让抽象议题可感可议。课前可安排学员搜集相关新闻。

3. **立场多元**：争议性议题（如"AI该不该有情感"、"AI创作是否算艺术"）不预设标准答案，鼓励学员从多角度思考，培养"理由-证据-立场"的论证习惯。

4. **辩论赛认真组织**：第13课辩论赛是本级别的高潮，建议提前分组、明确辩题、制定规则，可邀请其他班级或家长观赛，仪式感拉满。

5. **研究报告是重头戏**：第16-18课结业项目要求学员独立完成一份有观点、有证据的AI研究报告。选题范围放宽（可结合个人兴趣），教师提供研究方法指导，答辩环节邀请多方评审。

6. **守则要落地**：第15课"个人AI使用守则"不是纸上谈兵，建议与家庭沟通（家长参与签字），并在结业典礼上作为"AI公民承诺"宣读，让素养教育落到实处。

7. **全课程收束**：第19课大回顾应帮助学员画出完整的"AI素养地图"，明确四级课程的内在逻辑（会用→懂→驾驭→思辨），并串联LMCC全部考点，让学员带着完整的知识框架走出课堂。
